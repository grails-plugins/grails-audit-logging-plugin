== Description

The Audit Logging plugin adds customizable audit tracking when domain classes implement the `Auditable` trait. It also supports create and update user stamping with the `Stampable` trait.

=== Grails 8 Runtime and CLI Architecture

Plugin 7.x supports Grails 8 and Java 21 only. Applications declare the runtime `audit-logging` artifact. Its `Grails-Cli-Artifact` manifest entry identifies `org.grails.plugins:audit-logging-cli`, which Grails 8 provisions only for CLI execution. This keeps CLI dependencies out of application startup and packaged artifacts while making `audit-quickstart` available from the direct Grails CLI and interactive shell.

Plugin 7.x does not support Grails 7. Use plugin 6.x for Grails 7 applications. Existing historical plugin lines remain available for earlier Grails releases.

=== GORM Compatibility

Since plugin 5.x, auditing participates in the current Hibernate transaction and requires a Hibernate datastore. Persistence events from non-Hibernate datastores are not audited. The audit domain may use the same Hibernate datasource as the audited entity or another configured Hibernate datasource.
