== Installation

=== Prerequisites

The 7.x plugin line supports Grails 8 and Java 21 only. Use the 6.x plugin line for Grails 7 applications.

=== Repository and Runtime Dependency

Applications use only the runtime plugin dependency. During 7.0.x snapshot development, configure the scoped Maven Central Snapshots repository and add the snapshot version in `build.gradle`:

[source,groovy,subs="attributes+"]
----
repositories {
    maven {
        url = uri('https://central.sonatype.com/repository/maven-snapshots/')
        mavenContent { snapshotsOnly() }
        content {
            includeModule('org.grails.plugins', 'audit-logging')
            includeModule('org.grails.plugins', 'audit-logging-cli')
        }
    }
}

dependencies {
    implementation 'org.grails.plugins:audit-logging:{version}'
}
----

When released 7.x artifacts are available, use the released version from Maven Central. The snapshot is not a final release, and availability depends on publication.

=== Automatic CLI Companion

Do not add `org.grails.plugins:audit-logging-cli` to the application. The runtime JAR advertises that companion with the `Grails-Cli-Artifact` manifest entry. Grails 8 provisions the companion only for CLI execution, so its dependencies stay out of `bootRun`, `bootJar`, and `bootWar`.

=== Create the Audit Domain Artifact

For a new application, run quickstart once with the direct Grails CLI:

[source,shell]
----
grails audit-quickstart org.example.audit AuditLogEvent
----

Or start the interactive shell and run the same command:

[source,shell]
----
./gradlew shell
grails> audit-quickstart org.example.audit AuditLogEvent
----

The command creates the audit domain class and registers it with `grails.plugin.auditLog.auditDomainClassName`. Open the generated class to adjust mappings and constraints for the application. Preserve its required nullability constraints, then update the database schema through DDL or the database-migration plugin.

The generated `dateCreated` and `lastUpdated` properties default to `java.util.Date`. Both properties may use any type supported by Grails' `DefaultTimestampProvider`, but they must use the same type.

`audit-quickstart` is a legacy script packaged in `META-INF/commands`, not an `ApplicationCommand`. Do not use `runCommand` or expect a generated `auditQuickstart` Gradle task.

=== Next Steps

Add the `Auditable` trait to every domain class that should be audited:

[source,groovy]
----
import grails.plugins.orm.auditable.Auditable

class MyDomain implements Auditable {
    String value
}
----

To enable stamping, add the `Stampable` trait as well:

[source,groovy]
----
import grails.plugins.orm.auditable.Auditable
import grails.plugins.orm.auditable.Stampable

class MyDomain implements Auditable, Stampable {
    String value
}
----

See <<configuration,Configuration>> to configure audit behavior.
